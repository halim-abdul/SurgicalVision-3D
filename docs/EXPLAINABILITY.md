# Explainability and Auditability

Use explainability as an analysis tool, not proof of causal reasoning.

Recommended artifacts:
- class activation maps for image classifiers;
- attention rollouts for transformer encoders;
- overlayed segmentation uncertainty;
- spectral saliency by wavelength;
- disparity confidence maps;
- geometry residual heatmaps;
- decision-tree trace showing why an input was accepted/reviewed/rejected.

Each qualitative figure should include the model version, preprocessing state, confidence and known corruption condition.
