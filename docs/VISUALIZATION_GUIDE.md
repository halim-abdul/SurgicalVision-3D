# Visualization Guide

Recommended research figures:

1. frame + predicted surgical phase + confidence timeline;
2. RGB + segmentation overlay + uncertainty map;
3. hyperspectral false-color image + representative spectra;
4. rectified left/right stereo with epipolar lines;
5. disparity/depth heatmap with invalid region mask;
6. 3D point cloud and registered cloud pair;
7. reconstruction residual heatmap;
8. confusion matrix and calibration curve;
9. corruption-severity robustness curves;
10. quality-control decision trace.

Every figure should state whether it is synthetic, public benchmark, or governed research data.
